# 别皱眉 · KEPT IN STARS（Glass 星座海报风）

以金山文档《别皱眉》人设卡为内容，参考「玻璃星座海报」风格设计的移动端网页。

- 纸白噪点 + 星尘底、大号衬线混排标题（正体 + 斜体）
- 纯 CSS 灰调月球 / 土星 / 地球装饰，canvas 生成噪点与星空 —— **全站无 SVG**
- CSS 手机样机、整页吸附翻页、页码计数、MENU 索引、明暗主题切换
- 内容：关于我 / 风格特点 / 须知价格表 / 单前后注意事项 / 观我久往 / 话术堆砌

纯静态，浏览器打开 `index.html` 即可。
